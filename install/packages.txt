# Every package install.sh installs on the device, one per line. Shared with
# scripts/build_offline_bundle.sh, which downloads exactly these (plus their dependencies)
# for an offline install - keeping the two in sync by keeping them in one file.
#
# Names are Raspberry Pi OS names, which are not always Debian's: the "pix" boot splash is
# rpd-plym-splash rather than one of Debian's plymouth-theme-* packages.

# The kiosk browser: WPE WebKit's cog, straight on the display through DRM/KMS - no X, no
# window manager, no display manager (autologin on tty1 runs kiosk/cog-session). It replaced
# Chromium under X/Openbox, whose renderer crashed on page changes (install/kiosk/cog-session).
# A device installed before keeps its X and Chromium packages until an OS bundle removes them.
cog
# Video in WebKit is GStreamer, and its plugins are only Recommends - which install.sh leaves out:
# the ranking's podium videos are VP9 in WebM (matroskademux and vp9dec are in -good), WebKit's
# video sink needs the GL elements, decodebin and the converters are in -base.
gstreamer1.0-plugins-base
gstreamer1.0-plugins-good
gstreamer1.0-gl
# The UI's own icons are SVG (templates/icons/), but nicknames entered on a phone or PC
# can carry emoji - without a colour emoji font those are empty boxes on the kiosk.
fonts-noto-color-emoji

# Boot splash, carried over from the original project's setup.
plymouth
rpd-plym-splash

# App runtime. Only the engine: Compose v2 is not packaged for Raspberry Pi OS at all, so
# install.sh fetches Docker's own plugin binary (pinned in versions.env). Since trixie the
# `docker` client is its own package, only a Recommends of docker.io - and install.sh runs
# with --no-install-recommends, so without it the daemon runs and nothing can talk to it.
docker.io
docker-cli

# Standalone WiFi access point. rfkill because Raspberry Pi OS soft-blocks the radio until a
# WiFi country is configured - an image set up for ethernet only boots with it blocked.
hostapd
dnsmasq
rfkill

# The update watcher (inotify), the DS3231 (i2c-tools for diagnosis), and hwclock - which
# lives in util-linux-extra since bookworm and is what install/rtc_sync.sh calls.
inotify-tools
i2c-tools
util-linux-extra

# Fetching and unpacking during the install itself.
curl
ca-certificates
rsync
python3
